# AGENTS — Plataforma de Análisis Cultural · web

## Autoridad y representación
Este repositorio produce la web, la demo y un laboratorio piloto. No controla por sí mismo el canon científico de Tesis UPN, el catálogo Zotero, los originales, las publicaciones Zenodo o el conector privado ChatGPT. Una revisión guardada en navegador o un HTTP 200 no certifica una interpretación académica.

## No solapamiento operativo
- Convergencia por identificadores y relaciones verificables; disgregación entre fuentes, datos, interpretación, decisiones humanas, producto y publicación; modularización por propietario.
- La demo puede funcionar localmente sin implicar persistencia de laboratorio. D1 autenticada, Cloudflare Access y el MCP privado requieren verificaciones diferentes; si el endpoint falla cerrado, no saltarse el control.
- Conservar estados separados: propuesta, piloto, previsualización, borrador, validación, despliegue comprobado y lanzamiento aprobado.
- No publicar corpus personal, archivos multimedia de terceros, claves, tokens o payload privado como datos de frontend/issue. Copias de distribución justificadas son derivadas, no obras nuevas; mantener versión y hashes.
- Ajustar formato, redacción, accesibilidad y citas a la audiencia web; enlazar al dueño académico o documental, no clonar bibliotecas de artículos.

## Operación
Consultar los issues propietarios #12 (Access/D1), #13 (piloto de conversación) y #14 (MCP remoto) antes de actuar. Probar solo código modificado y comprobar el despliegue real; no asumir autorización ni cumplimiento desde la mera existencia de archivos. GitHub y conectores primero; Desktop Commander únicamente si es indispensable y en tanda acotada.

## Política rectora transversal
La [política de no solapamiento por entidad, atributo, versión y ámbito](https://github.com/ceoncoyb/gitbridge-source-intake/blob/main/okf/policies/non-overlap-adaptive-projection-20261014.md) gobierna las relaciones con Zotero, Obsidian, GitBridge, Zenodo/DOI y archivos originales. Este archivo define solo las exigencias de proyección web; no replica la política ni modifica el canon académico.
