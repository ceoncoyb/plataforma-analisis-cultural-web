ALCANCE

Una estructura común. Cada campo conserva su método.

Organiza evidencia de productos digitales, campañas, interfaces, entrevistas, películas, servicios, archivos o sistemas. El campo del estudio orienta el análisis; no impone una teoría ni una plantilla única. Esta demo registra notas y localizadores: no ejecuta el análisis generativo del conector privado.
