ALCANCE

Un laboratorio, muchos tipos de producto.

El mismo flujo organiza evidencia sobre productos digitales, campañas, interfaces, entrevistas, películas, servicios, archivos o sistemas. El campo del proyecto orienta el análisis; no impone una teoría ni una plantilla única.

Alcance de esta demostración: el navegador guarda ficha y anotaciones localmente; exportar crea un JSON portable. No es la D1 ni escribe en el plugin conectado a ChatGPT. Los archivos de video/audio no se incluyen en el JSON: vuelve a seleccionarlos al reabrir el proyecto.
