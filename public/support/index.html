Ayuda técnica · canal público

Reporta un problema reproducible.

Para la web pública y la demostración local, el repositorio de GitHub sirve como canal de incidencias. Es público y requiere una cuenta de GitHub para participar.

Abrir incidencia en GitHub ↗

Antes de informar

Indica la ruta pública afectada, los pasos para reproducir el problema, el resultado esperado y el observado, el navegador y el sistema operativo. Puedes consultar las incidencias existentes para evitar duplicados.

Privacidad: no incluyas contraseñas, claves API, tokens de sesión, archivos del corpus, datos personales ni contenido de proyectos privados. Las incidencias y sus adjuntos son visibles públicamente y están sujetos a las condiciones de GitHub.

Qué está disponible

La demo general funciona localmente en el navegador. El laboratorio audiovisual es un piloto especializado; la sincronización protegida con D1 y las funciones de conversación con IA necesitan verificaciones separadas. Una vista previa de código no constituye un servicio abierto.

Alcance de este canal

Este canal permite documentar incidencias técnicas públicas y sugerencias. No ofrece soporte de emergencia, garantía de respuesta, acuerdo de nivel de servicio, contratación ni acceso a proyectos privados. Todavía no hay asistencia comercial o multiusuario publicada.

Para entender el tratamiento de los datos del navegador, consulta la política de privacidad de la web. No envíes información confidencial al repositorio público para obtener ayuda.
