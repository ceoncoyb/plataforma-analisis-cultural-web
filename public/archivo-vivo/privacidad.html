Privacidad de esta edición

La web pública de demostración no tiene formularios conectados a una base de datos, ni almacena pedidos en un servidor. El ticket informativo se genera únicamente en el navegador y no se remite al editor. El campo de alias es opcional. Si el usuario activa un enlace a PayPal o Ko-fi, se aplicarán las políticas del proveedor correspondiente.

Esta edición no publica correos, teléfonos, datos bancarios, conversaciones privadas ni notas personales de Obsidian. No recopila claves ni datos de tarjetas.

Las solicitudes comerciales reales podrán requerir una política más completa antes de activar cobros y registrar datos de clientes.
