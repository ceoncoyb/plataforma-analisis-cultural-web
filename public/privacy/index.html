Privacidad · versión 1.0 · 12 de octubre de 2026

Tu material de investigación merece límites claros.

Esta página describe el sitio informativo y el laboratorio local de la Plataforma de análisis cultural. La integración MCP privada es un servicio separado y no se conecta desde esta web.

1. Datos que introduces en el laboratorio

El nombre, campo, pregunta, unidades y anotaciones del laboratorio se guardan en localStorage del navegador y dispositivo que utilizas. Los medios seleccionados (video, audio, imágenes y documentos) se previsualizan desde memoria local y no se suben; tendrás que seleccionarlos de nuevo al iniciar otra sesión. Los archivos multimedia no se incluyen en el JSON exportado. El sitio no envía este material a un servidor, no lo incorpora a una cuenta ni lo procesa con un modelo. Si importas un JSON, su contenido puede guardarse localmente junto a las anotaciones; evita importar datos que no deban permanecer en ese dispositivo. Puedes exportar tu ficha y borrar el espacio desde el laboratorio, o retirar el almacenamiento del navegador desde los ajustes del sitio.

Evita introducir información personal, datos confidenciales o fragmentos protegidos si no tienes autorización para usarlos.

2. Datos técnicos del sitio

El alojamiento de Cloudflare puede recibir la información técnica necesaria para entregar y proteger las páginas, como dirección IP, solicitud, agente de usuario y registros de seguridad. Esta web no incorpora Google Analytics, píxeles publicitarios, formularios de correo ni fuentes tipográficas remotas. Para detalles sobre tratamiento por infraestructura, consulta la política de privacidad de Cloudflare.

3. Cookies y analítica

La página pública no instala cookies de analítica o publicidad ni utiliza herramientas de seguimiento de terceros. El laboratorio guarda la ficha y las anotaciones en el almacenamiento local para mantenerlas tras una recarga. Los medios seleccionados solo están disponibles durante la sesión abierta.

4. ChatGPT y el conector MCP

La integración actual de ChatGPT es un piloto privado separado. Al usarla, los datos que el usuario envía a sus herramientas se gestionan mediante los controles de esa plataforma y su almacenamiento asociado. Esta política de la web no describe ni reemplaza la política que se requerirá para una futura versión pública multiusuario. El lanzamiento a terceros no se abrirá hasta publicar los permisos, finalidades, retención, exportación y eliminación correspondientes.

5. Tus controles

  • Elimina una anotación con “Quitar” o reinicia el proyecto y sus datos locales con “Limpiar espacio”.
  • Elimina el almacenamiento local desde los ajustes de datos del navegador para retirar las unidades guardadas de este sitio.
  • La descarga está bajo tu control; puedes borrar el archivo desde tu dispositivo.

6. Cambios y contacto

Esta política se actualizará antes de integrar cuentas, formularios, analítica, pagos o un servicio público de almacenamiento. No se reciben consultas personales a través de esta página. Si decides enviar una incidencia o sugerencia a GitHub, los datos que publiques allí quedan sujetos al servicio y política de GitHub; no se envían al laboratorio. Para comunicar un problema con el código o proponer una función, usa el repositorio público.
