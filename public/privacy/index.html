Privacidad · versión 1.0 · 12 de octubre de 2026

Tu material de investigación merece límites claros.

Esta página describe el sitio informativo y el sandbox público de la Plataforma de análisis cultural. La integración MCP privada es un servicio separado y no se conecta desde esta web.

1. Datos que introduces en el sandbox

El nombre del estudio, el campo y la pregunta permanecen en memoria de la página mientras la tienes abierta. Las unidades que añades se guardan mediante localStorage en el navegador y dispositivo que utilizas. La ficha descargada se genera en tu dispositivo. El sitio no envía estos campos a un servidor, no los incorpora a una cuenta ni los procesa con un modelo. Los medios seleccionados (video, audio, imágenes y documentos) se previsualizan desde memoria local y no se cargan al servidor. El navegador puede conservar las unidades hasta que las borres o elimines los datos del sitio. Esta regla corresponde a la demo general; el laboratorio audiovisual tiene el tratamiento adicional descrito a continuación.

Evita introducir información personal, datos confidenciales o fragmentos protegidos si no tienes autorización para usarlos.

2. Laboratorio audiovisual y D1

El manifiesto del plugin, la ficha fuente y los archivos de video/audio se procesan en la pestaña y no se cargan en el servidor. El laboratorio incluye código para sincronizar exclusivamente el borrador de decisiones de revisión —ID y revisión del proyecto, ID del candidato, estado, tiempos, nota, procedencia e información de cotejo— con una D1 de Cloudflare separada del conector privado. La sincronización remota sigue pendiente de una prueba autenticada en producción: no debe asumirse que se haya enviado ni recuperado información desde D1. El borrador local permanece en localStorage aunque la ruta remota esté deshabilitada. El diseño de D1 separa registros por identidad, proyecto y revisión, pero dicho aislamiento aún requiere verificación operativa. La D1 de Pages es independiente del almacenamiento privado del conector MCP; este flujo no escribe en el MCP.

El acceso remoto requiere Cloudflare Access configurado y una lista explícita de identidades autorizadas. Si faltan esos parámetros, la API rechaza las solicitudes y el navegador conserva la copia local. No se ha confirmado una sesión autenticada funcional; la incidencia #12 conserva la prueba pendiente. El flujo está diseñado para no enviar bytes de medios ni el manifiesto fuente. Cuando D1 esté habilitada y comprobada, el panel permitirá borrar la revisión remota de forma separada del almacenamiento local.

3. Datos técnicos del sitio

El alojamiento de Cloudflare puede recibir la información técnica necesaria para entregar y proteger las páginas, como dirección IP, solicitud, agente de usuario y registros de seguridad. Esta web no incorpora Google Analytics, píxeles publicitarios, formularios de correo ni fuentes tipográficas remotas. Para detalles sobre tratamiento por infraestructura, consulta la política de privacidad de Cloudflare.

4. Cookies y analítica

La página pública no instala cookies de analítica o publicidad ni utiliza herramientas de seguimiento de terceros. El sandbox utiliza almacenamiento local del navegador para que las unidades de demostración sobrevivan al cambio de página o recarga.

5. ChatGPT y el conector MCP

La integración actual de ChatGPT es un piloto privado separado. Al usarla, los datos que el usuario envía a sus herramientas se gestionan mediante los controles de esa plataforma y su almacenamiento asociado. Esta política de la web no describe ni reemplaza la política que se requerirá para una futura versión pública multiusuario. El lanzamiento a terceros no se abrirá hasta publicar los permisos, finalidades, retención, exportación y eliminación correspondientes.

6. Tus controles

  • Borra las unidades con “Quitar” o toda la ficha con el botón “Borrar ficha”.
  • Elimina el almacenamiento local desde los ajustes de datos del navegador para retirar las unidades guardadas de este sitio.
  • La descarga está bajo tu control; puedes borrar el archivo desde tu dispositivo.

7. Cambios y contacto

Esta política se actualizará si cambian los controles de acceso, los datos sincronizados, la finalidad o el plazo de conservación. No se reciben consultas personales a través de esta página. Si decides enviar una incidencia o sugerencia a GitHub, los datos que publiques allí quedan sujetos al servicio y política de GitHub; no se envían al sandbox. Para incidencias técnicas públicas, consulta Soporte o el repositorio público. Nunca publiques corpus privado, credenciales ni datos personales de terceros en una incidencia.
