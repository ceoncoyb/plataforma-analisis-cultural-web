Privacidad · versión 1.0 · 12 de octubre de 2026

Tu material de investigación merece límites claros.

Esta página describe el sitio informativo y el sandbox público de la Plataforma de análisis cultural. La integración MCP privada es un servicio separado y no se conecta desde esta web.

1. Datos que introduces en el sandbox

El nombre del estudio, el campo y la pregunta permanecen en memoria de la página mientras la tienes abierta. Las unidades que añades se guardan mediante localStorage en el navegador y dispositivo que utilizas. La ficha descargada se genera en tu dispositivo. El sitio no envía estos campos a un servidor, no los incorpora a una cuenta ni los procesa con un modelo. El navegador puede conservar las unidades hasta que las borres o elimines los datos del sitio.

Evita introducir información personal, datos confidenciales o fragmentos protegidos si no tienes autorización para usarlos.

2. Datos técnicos del sitio

El alojamiento de Cloudflare puede recibir la información técnica necesaria para entregar y proteger las páginas, como dirección IP, solicitud, agente de usuario y registros de seguridad. Esta web no incorpora Google Analytics, píxeles publicitarios, formularios de correo ni fuentes tipográficas remotas. Para detalles sobre tratamiento por infraestructura, consulta la política de privacidad de Cloudflare.

3. Cookies y analítica

La página pública no instala cookies de analítica o publicidad ni utiliza herramientas de seguimiento de terceros. El sandbox utiliza almacenamiento local del navegador para que las unidades de demostración sobrevivan al cambio de página o recarga.

4. ChatGPT y el conector MCP

La integración actual de ChatGPT es un piloto privado separado. Al usarla, los datos que el usuario envía a sus herramientas se gestionan mediante los controles de esa plataforma y su almacenamiento asociado. Esta política de la web no describe ni reemplaza la política que se requerirá para una futura versión pública multiusuario. El lanzamiento a terceros no se abrirá hasta publicar los permisos, finalidades, retención, exportación y eliminación correspondientes.

5. Tus controles

  • Borra las unidades con “Quitar” o toda la ficha con el botón “Borrar ficha”.
  • Elimina el almacenamiento local desde los ajustes de datos del navegador para retirar las unidades guardadas de este sitio.
  • La descarga está bajo tu control; puedes borrar el archivo desde tu dispositivo.

6. Cambios y contacto

Esta política se actualizará antes de integrar cuentas, formularios, analítica, pagos o un servicio público de almacenamiento. No se reciben consultas personales a través de esta página. Si decides enviar una incidencia o sugerencia a GitHub, los datos que publiques allí quedan sujetos al servicio y política de GitHub; no se envían al sandbox. Para comunicar un problema con el código o proponer una función, usa el repositorio público.
